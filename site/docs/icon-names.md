The icon names you can use for links and social profiles. Names aren't case-sensitive. A name that doesn't exist stops the build, usually with a suggestion such as `Did you mean "calendar"?`; otherwise the hint lists the known names.

## Link icons

A link's `icon` is any icon name from [Lucide](https://lucide.dev/icons), for example `globe`, `mail`, `book-open` or `shopping-cart`. Search the Lucide site and copy the name shown under the icon. [Links and icons](links-and-icons.md) shows how to use them.

## Social types

A social profile's `type` is a brand's slug on [Simple Icons](https://simpleicons.org), which covers thousands of brands. The slug is usually the name in lowercase, without spaces or dots; spaces and dots in `type` are ignored. These are the common ones, with the name screen readers announce unless you set a `label`:

`twitter` is another name for `x`, and `mail` for `email`. `email` and `website` use Lucide's envelope and globe; `linkedin`, `dribbble` and `figma` use logos that come with linkprofile. [Social profiles](social-profiles.md) shows how to add them.
